# Caça ao Tesouro

Projeto acadêmico desenvolvido em linguagem C para praticar lógica de programação e fundamentos de algoritmos.

## Objetivo

Desenvolver um jogo de exploração em terminal no qual o jogador precisa encontrar tesouros em um tabuleiro, evitando armadilhas.

## Conceitos utilizados

- Variáveis e operadores;
- Estruturas condicionais (`if`, `else` e `switch`);
- Estruturas de repetição;
- Matrizes bidimensionais;
- Vetores unidimensionais;
- Validação de entrada;
- Ordenação Bubble Sort.

## Tecnologias

- Linguagem C;
- GCC;
- Visual Studio Code.

## Execução

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic src/main.c -o jogo.exe
./jogo.exe
```
